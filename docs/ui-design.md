### 1.4 デザインシステムのルール (readme.md より)
- ボタンの文字は左寄せにする (中央に揃えない)
- 2px の区切り線を細い線に変えたり、余白で置き換えたりしない
- 朱色は主要な操作と小さな強調にだけ使う
- 守らせる仕組み: ESLint で、クラス名に `rounded-` `shadow-` `ring-offset-` を書いたら警告にする。書き出したファイルの `_adherence.oxlintrc.json` に同じ趣旨のルールがあるので、それを元にする

### 1.5 ダークモードの考え方

デザインにはライトモードしかないので、次の方針で導いた。

- **色の段階 (ramp) を反転させる**: ライトで neutral-N を使っている所は、ダークで neutral-(1000-N) 付近を使う (例: 行の線 300 → 800、控えめな文字 700 → 400)
- **朱色はモードで変えない**: ブランド `#ec3013` も、文字を載せる面 `#dd2b0f` も、ライトと同じにする。hover と押したときは、白い文字が読めるように、どちらのモードでも暗い方へずらす (デザインシステムの readme は「暗い背景では明るい方へ」としているが、白い文字のコントラストを優先する)
- **朱色の文字だけ明るくする**: ライトの 700 (`#ae1800`) は暗い背景では読めないので、500 (`#ff563c`) にする
- **書影の色は変えない**: 写真を白黒にするのはデザインシステムのルールだが、書影は商品の情報なので白黒にせず、そのまま出す (ライトと同じ)

コントラスト比 (ダークの背景 `#1a1918` に対して。計算済み):

| 色 | 比 | 判定 |
|---|---|---|
| 文字 `#f3f2f2` | 15.7 | AA |
| 控えめな文字 `#bab6b6` | 8.7 | AA |
| さらに控えめな文字 `#9b9797` | 6.1 | AA |
| 朱色の文字 `#ff563c` | 5.6 | AA |
| 朱色 (ブランド) `#ec3013` | 4.2 | UI 部品の基準 (3:1) を満たす。文字には使わない |
| 太い区切り線 (文字色 35%) | 3.0 | UI 部品の基準 (3:1) を満たす |

朱色の面と白い文字 (§7-12 の案 B。どちらのモードも同じ):

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `#ffffff` on `#dd2b0f` (通常) | 4.74 | AA |
| `#ffffff` on `#ae1800` (ライトの hover・ダークの押したとき) | 7.17 | AA |
| `#ffffff` on `#c42309` (ダークの hover) | 5.85 | AA |
| `#ffffff` on `#7c1405` (ライトの押したとき) | 10.72 | AA |

ライトの背景の上の朱色の文字 `#ae1800` は 6.4:1 (AA)。デザインのモックでは、ナビやリンクの文字に `#ec3013` (3.8:1) を使っていたが、デザインシステムの readme にある「本文サイズの朱色の文字には 700 を使う」に合わせて `--accent-text` に揃える。

### 1.6 テーマの切り替え

- `next-themes` を使う (shadcn の公式の方法)。`<ThemeProvider attribute="class" defaultTheme="system" enableSystem disableTransitionOnChange>`
- 初期値は「端末の設定に合わせる」。ユーザーが選んだテーマは `localStorage` に保存する (DB には保存しない。ログインしていなくても使えるようにするため)
- `<html suppressHydrationWarning>`。テーマのクラスは描画前のスクリプトで付くので、ISR のページでも一瞬白く光らない
- CSS に `color-scheme: light` / `dark` を書き、スクロールバーやフォーム部品の色もテーマに合わせる
- `export const viewport = { themeColor: [{ media: "(prefers-color-scheme: light)", color: "#f3f2f2" }, { media: "(prefers-color-scheme: dark)", color: "#1a1918" }] }`
- 切り替えボタン: ヘッダーの右端 (アバターの左) に、アイコンだけのボタン (`Sun` / `Moon`) を置く。押すと `DropdownMenu` で「ライト」「ダーク」「端末の設定に合わせる」を選ぶ。スマホではヘッダーのメニューの中に入れる

## 2. 共通の部品

shadcn/ui の部品を `npx shadcn@latest add` でコピーし、コピーした直後に次の共通の直しを入れる。

- `rounded-*` `shadow-*` `ring-offset-*` を外す
- ボタン系の `justify-center` を `justify-start` にする (文字を左寄せ)
- hover と押したときの色を `--primary-hover` / `--primary-active` にする
- フォーカスリングを §1.3 の形に揃える

Radix を使う部品はクライアント部品になる。操作のある所だけで使い、カードや表など表示だけの部分は Server Component のまま描く。

| デザインの部品 | 使う shadcn の部品 | 直すところ・補足 |
|---|---|---|
| `SiteHeader` | — (自作) | sticky、下に 2px の線。中は `max-width:1240px`、`padding:12px 24px`、`gap:24px`。ロゴ (朱色の 18px の■ + 文字)、ナビ「ホーム」「さがす」、検索欄、テーマ切替 (§1.6)、アバター (30px の■にイニシャル。背景は文字色、文字は背景色) + 名前 + 「ログアウト」/ 未ログインなら「ログイン」 |
| 検索欄 | `Input` | 背景は面の色、左に虫眼鏡、最大幅 460px。フォーカス時は枠を `--brand` に |
| `Button` (primary / secondary / ghost / icon) | `Button` (variant: default / outline / ghost、size: icon) | 影を外し、文字を左寄せにする。default は `--primary` の面に白い文字。ghost の文字は `--accent-text` |
| `Segmented` (AND/OR・並び順・表示) | `ToggleGroup` (`type="single"`) | 選んだ方を `--primary` で塗り、文字は白。区切りは 1px の `--border`。何も選ばれていない状態にならないようにする (選択中をもう一度押しても外れない) |
| `FilterChip` | `Toggle` | 枠 1px の `--chip-border`、`padding:5px 10px`、13px + 件数 11px。選択中は `--primary` で塗り、文字は白 (`aria-pressed`)。0件は `disabled` で opacity 0.4 |
| `TagLink` | `Badge` (variant `outline-primary` を追加) | 枠は `--brand`、文字は `--accent-text`、13px。`<Link>` として描き (`asChild`)、hover で `--accent-tint` |
| `SelectedTag` | `Badge` (variant `tint` を追加) + `X` アイコン | `--accent-tint` の面。押すと外れる |
| `CoverImage` | — (自作) | `next/image`、3:4、背景は面の色。書影がないときはアイコンを出す |
| `SectionHeading` | — (自作) | 上に 2px の文字色の線、`padding-top:14px`、左に h2、右に補足 (12px、`--muted-foreground`) |
| `SeriesCard` | — (自作) | shadcn の `Card` は角丸・影・余白が前提で、デザインのカード (面のない書影 + 文字) とは別物なので使わない (§2.1) |
| 新刊カレンダー・巻一覧 | `Table` | 見出し行は 11px・字間 .06em、下に 1px の `--border`。行の下に 1px の `--line`、hover で `--accent` (§2.2、§3.3.1) |
| 巻一覧の「すべての巻を表示」 | `Collapsible` | — |
| スマホの絞り込みパネル | `Sheet` (下から出す) | 角丸を外す |
| ヘッダーのメニュー (スマホ)・テーマの選択 | `DropdownMenu` | 角丸・影を外し、枠 1px の `--border` にする |
| ログイン画面・マイページのフォーム | `Form` (react-hook-form + zod) + `Input` + `Label` | zod のスキーマは API の入力検証と共通にする |
| お気に入りの追加などの通知 | `Sonner` | 角丸・影を外し、枠 1px。テーマは `next-themes` に合わせる |
| 読み込み中の表示 | `Skeleton` | 書影と同じ 3:4、面の色。角丸なし |
| マイページのタブ (お気に入り / 読了 / プロフィール) | `Tabs` | 選択中のタブは下に 2px の `--brand` の線 |

### 2.1 作品カード (`SeriesCard`)

| 種類 | 表示する内容 | 使う場所 |

## 3. 画面ごとの仕様

### 3.1 ホーム `/`

上から順に、間隔 56px:

| # | セクション | 中身 |
|---|---|---|
| 1 | **あなたへのおすすめ** (ログイン時) | 補足「お気に入り・読了した作品から選んでいます」。`recommend` カードを6枚 |
| 1' | (未ログイン時) | 面の色 (`--muted`) に「あなたへのおすすめ」+「ログインすると、お気に入り・読了した作品をもとにおすすめが表示されます。」+ `Button` (default)「ログイン」 |
| 2 | **新作・新刊** | **最近発売されたシリーズからランダムに12枚**選び、`release` カードで出す。表示を開くたびに入れ替わる。補足は「最近発売された作品からランダムに表示」 |
| 3 | **新刊カレンダー** (案 B) | 最近発売されたシリーズを、**発売日の新しい順に表**で出す (`ReleaseCalendarRow`)。右上に「{n}シリーズ」。最初は30行で、「さらに見る」で30行ずつ足す |

「最近発売された」の定義:
- `latest_published_date` が **今日 (JST) から30日前〜今日** の範囲にある親シリーズ。未来の日付 (発売予定) は含めない (§7-9)
- 範囲内が12件に満たないときは、日付の新しい順に上位100件まで広げて、そこからランダムに選ぶ
- セクション2と3は同じ候補の集合を使う。2はその中からランダムに選び、3は全件を日付順に並べる

推薦理由のラベルの種類 (デザインに出てくるもの): 「『X』と同じ著者」「#A #B がお気に入りに近い」「#A #B の傾向から」「『X』の読者に人気」

### 3.2 さがす `/search`

- 件数 (12px、`--muted-foreground`) + h1 (34px)。h1 の文言は条件によって変える:
  - 入力した語がある: 「『〇〇』の検索結果」
  - タグだけで絞っている: 「タグで絞り込み」
  - 条件なし: 「すべてのシリーズ」
- 絞り込みの表: 上に 2px の `--foreground` の線。行ごとに、左 110px に分類名と「N件選択」(`--accent-text`)、右に `FilterChip` を並べる。行の下に 1px の `--line`
  - チップの件数: **入力した語だけで絞った集合**で、そのタグを持つ作品の数 (デザインの `base` と同じ)
  - チップの並び: 選んだもの → 件数の多い順
  - **サブジャンルは 883 種類ある**ので、最初は件数の多い30個だけを出し、残りは「すべて表示 (ほかN件)」(`<details>`) で開く (2026-10-16 の実装)
- 条件の行 (下に 2px の divider): 複数タグの条件 `Segmented` / 並び順 `Segmented` [**新しい順 (初期値)** | 人気順 | タイトル順] / 表示 `Segmented` / 「条件をリセット」(`Button` ghost、条件があるときだけ右端に出す)
- 結果は48件ずつ「さらに見る」で追加する
- タグを選んでいるとき: 「すべて含む：」(OR のときは「いずれかを含む：」) + `SelectedTag` を並べる
- 0件のとき: 「該当するシリーズが見つかりませんでした」(18px 800) + 「タグを減らすか、条件を『いずれか（OR）』にしてみてください。」+ `Button` (outline)「条件をリセット」
- 結果: `cover` (書影ビュー) または `list` (リストビュー)
- 入力した語は、タイトル・著者・イラストレーター・レーベル・あらすじ・タグ名のどれかに含まれていれば一致とする (デザインの `matchQuery` と同じ範囲)

### 3.3 作品詳細 `/series/[id]`

- 戻るボタン (`Button` ghost、文字は `--foreground`): 来た画面によって「検索結果に戻る」/「ホームに戻る」
- 2段組 (間隔 48px、狭い画面では折り返す):
  - 左: 書影 (幅 280px)
  - 右 (間隔 24px):
    1. メタ情報 (12px 700、`--accent-text`): 「白鷺文庫 ／ 全3巻 ／ 最新刊 2026/10/10」
    2. h1 34px 作品名
    3. 「著者名　／ イラスト 〇〇」(イラストの部分は `--muted-foreground`)
    4. タグの表: 上に 2px の divider。行は「分類名 96px + `TagLink`」
    5. ボタン: お気に入り (`Button` default「お気に入りに追加」→ 登録後は outline「お気に入り済み」) / 読了 (`Button` outline「読み終わった」→ 登録後は「読了済み」)
    6. h6「あらすじ」+ 本文
    7. **巻一覧** (h6「巻一覧」+ 表。デザインにないので追加。§3.3.1)
- 「似ているシリーズ」: `SectionHeading` (24px、補足は「他の作品のおすすめ」) + `similar` カード6枚

#### 3.3.1 巻一覧 (`VolumeTable`)

shadcn の `Table` を使い、案 B の新刊カレンダーと同じ行の作りにする。

| 列 | 幅 | 中身 |
|---|---|---|
| 巻 | 64px | 「1」「2」…。上中下は「3 上」のように `volume_number_sub` を足す。巻数がないものは「—」 |
| 書影 | 40px | 3:4 の小さい書影 |
| タイトル | 残りの幅 | 書籍のタイトル (15px 700)。特装版が紐付いているときは、その下に「特装版あり」(11px、`--accent-text`) |
| 発売日 | 96px | 「2026/10/10」(13px) |

- 並び順: `volume_number` の昇順 → `published_date` の昇順 (今の API と同じ)
- 特装版 (`attached_to_isbn` がある本) は行にしない。本編の行に「特装版あり」として出す
- 10巻を超えるときは、最初の10行だけ出し、「すべての巻を表示 (全N巻)」(`Collapsible` + `Button` ghost) で残りを開く
- 行を押すと、その巻の版元ドットコムのページを新しいタブで開く (ISBN から URL を作る)
- スマホ: 書影の列を消す

## 5. 推薦理由・共通点ラベルを作る仕組み

| ラベル | 作り方 (RPC の中) | 優先度 |
|---|---|---|
| 『X』と同じ著者 | 元にした作品 (お気に入り・読了) と `author` が一致する | 1 |
| 『X』の読者に人気 | その作品が、元にした作品のうち1つの「似ているシリーズ」の上位5件に入っているとき | 2 |
| #A #B がお気に入りに近い | 元にした作品と共通するタグのうち、`usage_count` の少ない (珍しい) 上位2つ | 3 |
| #A #B の傾向から | 上のどれにも当てはまらないとき。結果の作品のタグのうち、元にした作品に多いタグの上位2つ | 4 |
| 同じ著者 · #A #B (似ているシリーズ) | 著者が一致すれば「同じ著者」。それに**共通ジャンル**の珍しい順の上位2つを足す (候補はジャンルが2つ以上同じ作品なので、必ず共通ジャンルがある) | — |

- 「似ているシリーズ」の補足はデザインでは「タグと著者の共通点から」だが、実際の並び順はジャンルで絞ったうえで theme / mood / reader のベクトルの近さで決まり、表示とずれる。そのため補足は **「他の作品のおすすめ」** に変える

## 8. 2つの版 (書影あり / 書影なし) (2026-10-16)

同じコードから、見た目の違う2つのサイトを出す。ビルド時の環境変数 `NEXT_PUBLIC_UI_VARIANT` で切り替える (`src/lib/variant.ts`)。

| | 書影あり (`cover`、既定) | 書影なし (`nocover`) |
|---|---|---|
| 元にしたデザイン | 案 A「グリッド」(`design/mock/`) | 「書影なし」のあらすじ型 (`design/mock-nocover/`) |
| ホームのおすすめ・新作・新刊 | 書影のカード (新作・新刊は12件) | あらすじ型 (新作・新刊は6件) |
| 新刊カレンダー | 表 + 書影の列 | 表 (書影の列なし) |
| さがすの「表示」 | 書影 (初期値) / リスト | カード / 表 / あらすじ (初期値) |
| 詳細 | 左に書影、右に情報 | 大きなタイトル、巻数・最新刊・レーベルの帯、あらすじとタグの2列 |
| 巻一覧 | 書影の列あり | 書影の列なし |
| OGP の画像 | 書影 | なし |

- 版で変わるのは見た目の部品だけ。データの取得・検索・ログイン・お気に入りは共通
- 版で切り替える部品: `SeriesCollection` (ホーム・似ているシリーズ・マイページ)、`ResultsView` (さがす)、詳細ページの `CoverLayout` / `TextLayout`、`VolumeTable` と新刊カレンダーの書影の列
- 版にない表示を URL で指定されたとき (例: 書影ありの版で `?view=table`) は、その版の初期値で表示する
- ローカルで両方を同時に動かすときは、書影なしの版を `NEXT_DIST_DIR=.next-nocover` で別の置き場所にする (`.claude/launch.json` の `ranobe-next-nocover`、ポート 3101)
